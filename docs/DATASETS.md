## Dataset

For the unified benchmark, we use the **PrimeVul_v0.1 Paired** dataset, consisting of:
- primevul_test_paired.jsonl -> for testing
- primevul_train_paired.jsonl -> for knowledge base construction
- primevul_valid_paired.jsonl

The PrimeVul repository can be found [here](https://github.com/DLVulDet/PrimeVul) &
the latest release Google Drive Download folder [here](https://drive.google.com/drive/folders/1cznxGme5o6A_9tT8T47JUh3MPEpRYiKK).
